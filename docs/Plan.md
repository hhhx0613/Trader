# 量化交易系统计划（当前权威版）

> 更新：2026-09-13。本文是项目唯一权威架构与决策文档；`Plan_v2.md` 为历史归档，不再维护。

## 1. 当前目标与边界

目标不是证明 LLM 或 PPO 必然有效，而是在严格样本外和相同交易口径下，验证它们是否为选股或仓位决策提供可重复的增量价值。

- LLM：只产生个股级新闻/事件信号，候选用于选股；不参与总仓位择时。
- PPO：只决定周频总暴露；不改变 Top-K 选股和逆波动率个股权重。
- 公式波动率目标：PPO 的正式强基线，不是待替换的过渡实现。
- 规则风控：只能缩减仓位或否决交易，不凭空增加暴露。

## 2. 已确认的实验事实

统一最终回测区间：2025-08-11 至 2026-08-09；候选池为 10 只大盘龙头；初始资金为 $100,000。原始结果存放在 `output/`，每个实验的元数据见对应 `manifest.json`，横向比较见 `docs/experiment_index.csv`。

| 策略 | 累计收益 | 最大回撤 | 夏普 | 结论 |
| --- | ---: | ---: | ---: | --- |
| Buy & Hold（全池等权满仓） | 32.05% | 10.58% | 1.99 | 市场 beta 基准；风险暴露不同，不能直接作为低波动组合的 alpha 结论 |
| LLM Top-K + 公式暴露 | 10.00% | 5.90% | 0.87 | 当前 LLM 选股基线 |
| VADER Top-K + 公式暴露 | 12.04% | 4.53% | 1.22 | 当前最佳的同类简单信号基线 |
| PPO Top-K（旧日频模型） | 8.09% | 6.71% | 0.50 | 已淘汰：训练 env 与部署口径不一致 |
| PPO Top-K（新周频对齐模型） | 11.25% | 5.46% | 0.87 | 修复了迁移损失；尚未稳定胜过公式仓位 |

已证伪或暂停的方向：

- LLM 旁路用于 PPO 总仓位择时：消融收益增量约为 0、夏普略降；个股新闻信号聚合为组合级择时信号存在任务错配。
- 置信度校准：小样本下为负结果，保持否决。
- 旧日频 PPO：环境为等权随机池、日频决策及轻成本，与真实周频 Top-K 组合不一致，停止使用。

## 3. 当前有效架构

```text
PIT 新闻/财报 → LLM 个股事件评分 → Top-K 选股
                                      ↓
市场数值特征 + 账户状态 → 周频 PPO 或波动率目标公式 → 总暴露
                                      ↓
                         逆波动率个股权重 → 规则风控 → 执行
```

当前 PPO 训练/部署口径必须保持一致：全池感知市场特征、随机 5 股子池模拟持仓结构、逆波动率权重、ISO 周频决策、周内固定暴露、滑点加换手成本。训练使用 2015--2022，2023--2024 验证，2025-08--2026-08 为最终样本外窗口。

## 4. 当前核心问题

### 4.1 选股 alpha 未获证明（最高优先级）

LLM Top-K 在当前窗口落后于 VADER，因而尚不能声称 LLM 新闻分析带来选股增量。PPO 只能调节已有组合的风险暴露，不能补偿选股信号缺乏 alpha。

### 4.2 PPO 的经济价值尚未获证明

新 PPO 相比同一 LLM Top-K 的公式仓位，累计收益提高 1.25 个百分点，但夏普均为 0.87。单模型、单样本外路径不足以证明优势；更高收益也可能来自更高平均暴露。

### 4.3 目标与比较口径须一致

15% 波动率目标组合不应只与满仓 Buy & Hold 比绝对收益。所有结论均应优先比较相同股票池、调仓频率、成本和风险暴露下的策略；同时报告收益、夏普、最大回撤、平均暴露、换手和成本。

## 5. 后续工作与 Go/No-Go Gate

### A. PPO 对齐模型验收（先做）

在不加入 LLM Adapter 的前提下，完成新周频 PPO 的多种子和滚动样本外验证。

- 对照：同一 LLM Top-K、同一逆波动率权重和成本下的公式暴露。
- 必报：累计/年化收益、夏普、最大回撤、年化波动、平均暴露、换手、成本、逐周收益差。
- 统计：至少 3 个随机种子；按周 block bootstrap 给出 PPO 相对公式仓位的收益与夏普差异区间。
- **Go**：多数种子和样本外窗口中，夏普或最大回撤有稳定改善，且无明显成本恶化。
- **No-Go**：仅增加暴露从而提高绝对收益、夏普/回撤无稳定改善，或统计区间跨零且结果不稳定；PPO 降级为负/中性消融结果，保留公式仓位。

### B. 选股 alpha 审计（与 A 并列）

按周在同一候选池上比较 LLM、VADER、价格动量和随机排序。

- 指标：下周收益 Rank IC、Top-5 减 Bottom-5 收益、Top-K 相对全池收益、换手、持仓归因、行业暴露。
- 组合基准：固定 100% 暴露、公式暴露、等权与逆波动率权重分别比较；所有路径使用同一成本和 ISO 周锚定。
- **Go**：LLM 相对 VADER、动量和随机基准有跨窗口稳定的正增量。
- **No-Go**：没有稳定正 IC 或 Top-K 超额收益；停止将 LLM 作为主选股器，保留为研究/辅助解释工具。

### C. 技术面否决权消融（仅在 A/B 的基准固定后）

验证 LLM 入选股票加 EMA 趋势或 20 日动量门槛，是否减少“新闻利好但价格仍在下跌通道”的持仓。只比较该一个改动；若无稳定改善即删除。

## 6. 冻结项

在 A、B 的 Gate 通过前，不开展以下工作：

- 阶段二 Residual LLM Adapter；
- 多 Agent 编排；
- L2/L3/L4 记忆扩展；
- IBKR 模拟盘。

## 7. 实验存储与治理

- 每次回测输出一个不可覆盖目录：`output/backtest_<timestamp>/`，包含 `summary_<timestamp>.csv`、`equity_<timestamp>.csv`、`trades_<timestamp>.csv` 和 `manifest.json`。
- `manifest.json` 记录实验目的、代码提交、训练/验证/测试区间、股票池、选股/权重/暴露规则、成本、模型文件、随机种子、对照组与输出路径。
- `docs/experiment_index.csv` 一行对应一个已确认实验，用于横向比较和记录结论/决策；它不是自动生成报告。
- 不覆盖既有结果，不自动生成每次实验的 Markdown 报告；实验结论由人工审阅后更新索引与本文第 2 节。

## 8. 退出标准

项目的可答辩最低配置是：PIT 安全的信号管道、可复现回测、完整基准、选股 alpha 审计和 PPO 的明确 Go/No-Go 结论。任何未通过 Gate 的模块都应从主架构中移除，而不是继续叠加复杂度。
