# 提案：面向量化研究与模拟执行的可审计多 Agent 系统

**英文题目：** *An Auditable Multi-Agent System for Quantitative Research and Simulated Execution*

**状态：** 毕设研究提案讨论稿
**日期：** 2026-10-02
**实施权威文档：** [Plan.md](Plan.md)

## 1. 摘要

本项目探索一个从新闻、公告、财务披露、行情研究到模拟下单的量化 Agent 应用。核心目标不是让多个大语言模型（LLM）投票预测涨跌，也不是单纯追求回测收益最大化；而是建立一套可审计、时点安全、能够在证据不足时拒绝交易的决策系统。

系统将原始信息保存为带来源和时间戳的证据卡片，由事件、基本面、市场和风险审查等不同职责的 Agent 生成可追溯论点，最终由组合委员会在全股票池和当前持仓约束下形成动态的组合意图。观点校准与成本感知约束优化负责联合确定股票权重、现金和总暴露，风控与成本模型负责订单放行。每次决策均可回放“当时看到什么、谁提出何种论点、为何交易或观望、实际结果如何”。

## 2. 问题与动机

现有 LLM 量化研究常有四类不足：

- 将新闻摘要、推理和交易结论混在一次提示中，难以定位幻觉、时间泄漏和错误来源；
- 多 Agent 只做表面讨论，职责重叠，缺少可验证的反驳、拒答与升级机制；
- 选股结果常被固定 Top-K 或简单权重规则绑定，忽略当前持仓、换手成本、现金和不交易本身；
- 回测仅报告收益，无法说明某笔交易在决策时可获得的证据，以及系统是否稳定地作出了合理判断。

本项目把“研究过程可信”置于“单期收益更高”之前：收益、风险调整收益和换手只是验证指标，不是唯一优化目标。

## 3. 研究问题

1. 如何把异构金融数据组织为严格 point-in-time（PIT）的证据链，避免未来信息进入研究过程？
2. 如何让多 Agent 产生职责互补、可引用和可质疑的论点，而不是重复生成投资意见？
3. 当来源冲突、证据过期或论点分歧明显时，系统能否可靠地观望、降暴露或转交人工复核？
4. 如何让组合决策同时考虑持仓、交易成本、风险约束、现金和动态持股数量？
5. 如何以可复现的回测与消融实验，区分“模型恰好赚了钱”和“决策机制确有价值”？

## 4. 系统方法

系统由下列闭环构成：

```text
PIT 数据采集
  → EvidenceCard（原文、来源、可得时间、去重关系）
  → 个股研究 Agent（事件／基本面／市场／风险审查）
  → ClaimCard（带证据引用的论点、置信度、反证）
  → 组合委员会（全股票池动态 PortfolioIntent）
  → Signal Compiler → ConstrainedPortfolioOptimizer（股票权重、现金、总暴露、成本）
  → 确定性风控与模拟执行
  → OutcomeCard（结果归因）与记忆更新
```

### 4.1 证据优先的数据层

新闻、市场行情、公司披露、宏观与组合状态均以原始记录先入库。`EvidenceCard` 保存来源、URL、发布日期、抓取时间、可交易时间、原文或稳定摘要和内容哈希。媒体转载通过 URL、内容哈希和规范化文本去重/过滤，原始来源与冲突证据完整保留。

财务披露优先使用 SEC EDGAR 等公开来源，并以 filing acceptance/publication time 而非财年结束日作为 PIT 可得时间。LLM 只能基于被允许的证据引用进行解释，不能将未引用的背景知识伪装成当期事实。

### 4.2 分工而非投票的 Agent

| Agent | 输入 | 主要输出 |
| --- | --- | --- |
| Event | 本周新闻队列与公告 EvidenceCard | 事件、受影响主体、传导路径和不确定性 |
| Fundamental | 披露原文、结构化指标及事件论点 | 基本面变化、估值/盈利影响和反证 |
| Market | PIT 价格、成交量、波动和横截面状态 | 市场状态、拥挤/流动性与技术确认 |
| Risk Critic | 前述论点、当前持仓及约束 | 集中度、冲突、尾部风险和拒绝建议 |
| Committee | 全股票池 ResearchPacket 与组合状态 | 买入、持有、减仓、卖出、观望及理由 |

每个研究 Agent 面向单个资产输出结构化 `ClaimCard`；委员会同时比较整个股票池的卡片，并可按需查看原始证据。因此它可以选择零只、一只或多只股票，不受固定 Top-K 的产品约束。固定 Top-K 仅作为可比较的实验基线。

### 4.3 组合、成本与执行

委员会给出的不是最终订单或百分比权重，而是带条件、证据引用和不确定性的 `PortfolioIntent`。组合层按以下顺序运行：

1. `Signal Compiler` 将动作翻译为仓位边界，并将观点、证据覆盖率、冲突率、时效和 Risk Critic 结论校准为预期相对收益 `μ` 与不确定性；`μ` 表示预设持有期内相对基准的预期表现。
2. `ConstrainedPortfolioOptimizer` 用这些信号、股票协方差、当前持仓、流动性和成本，联合决定每只股票的**绝对账户权重**、现金权重、总暴露和换手。
3. `RiskProjection` 施加硬风险限制；`CostGate` 对具体订单进行最终成本放行。

优化器求解：

\[
\max_x\quad \hat{\mu}^{\top}x
- \lambda x^{\top}\hat{\Sigma}x
- \eta\,\mathrm{turnover}(x,x_{\mathrm{prev}})
- \kappa\,\mathrm{trading\_cost}(x,x_{\mathrm{prev}})
- \gamma\,\mathrm{uncertainty}(x)
\]

其中约束包含股票动作、单股/行业上限、流动性、最大换手和组合风险预算。现金权重为 `1 - sum(x)`，总暴露为 `sum(x)`；两者由同一次优化产生，而不是由两个互不关联的模块分别决定。风险引擎随后执行硬约束，模拟执行器在具体订单上重新校验佣金、滑点、最小交易单位和成交可行性。

### 4.4 组合层的科学依据与项目创新边界

组合层采用成熟金融理论，而非把 LLM 当作仓位生成器：

- [Markowitz（1952）](https://doi.org/10.1111/j.1540-6261.1952.tb01525.x) 给出预期收益、协方差与分散化的组合选择框架；
- [Black–Litterman（1992）](https://rpc.cfainstitute.org/research/financial-analysts-journal/1992/faj-v48-n5-28) 提供“中性先验 + 带置信度观点”的观点融合机制，适合将 Agent 结论以不确定性受控的方式注入组合层；
- [Jagannathan 与 Ma（2002）](https://www.nber.org/system/files/working_papers/w8922/w8922.pdf) 说明权重约束可降低大组合中的估计风险；
- [Lobo、Fazel 与 Boyd（2007）](https://stanford.edu/~boyd/papers/portfolio.html) 表明线性交易成本、风险与暴露约束可高效纳入组合优化。

因此，本项目的创新不宣称发明新的组合理论；创新在于把时点安全的多 Agent 证据、分歧、拒答和不确定性，转为可校准、可回放的组合观点输入，并在统一成本与风险条件下检验其是否带来增量价值。逆波动率、风险平价和 PPO 作为统一接口下的实验对照。

## 5. 预期创新点

1. **时点安全的证据—论点分层。** 将原始证据、LLM 推理和交易行动分开保存，使数据泄漏、引用错误和模型偏见可被审计。
2. **分歧驱动的拒答机制。** Agent 的冲突、陈旧证据和低置信度会进入明确的观望、降暴露或人工复核路径，而非被强行汇总为方向性交易。
3. **不确定性受控的全局组合决策。** 委员会以股票池、持仓和成本为上下文产生动态持股数量；Signal Compiler 将证据质量与分歧映射为预期相对收益和不确定性，约束优化器联合决定股票权重、现金、总暴露和换手。
4. **研究到执行的完整可回放闭环。** 以统一 `trace_id` 关联证据、论点、组合、订单和事后结果，支持消融、案例复盘与记忆校准。

## 6. 与相关工作的区别

| 工作 | 主要重点 | 本项目的区别 |
| --- | --- | --- |
| FinRL | 将交易表述为强化学习环境，重点是训练和策略收益 | 保留 RL 为可替换的组合政策，不把 RL 当作研究决策的主体；重点转为证据、审计和拒答。 |
| TradingAgents | 以多角色 LLM 讨论模拟交易团队 | 增加 PIT EvidenceCard、来源级可追溯、分歧阈值、确定性成本风控和端到端回放。 |
| AI-Trader / LLM 选股类系统 | 利用 LLM 解读新闻或文本形成交易信号 | 不让单次生成直接成为订单；用研究卡片、组合层决策和执行前成本门控连接文本研究与交易。 |
| FinMem、FinAgent 等记忆型金融 Agent | 用金融记忆提升长期推理或交易表现 | 记忆只保存经结果校准的可检索案例，并与证据版本、市场状态和 OutcomeCard 绑定。 |

这里的比较是设计定位，不预设本项目必然优于已有方法；最终通过统一数据、成本和 PIT 约束下的消融实验验证。

## 7. 评估设计

实验必须使用滚动 PIT 数据切分、统一股票池、统一交易日历、相同成本模型和可复现的配置快照。比较对象包括：无 LLM 的 VADER/动量基线、单 LLM 选股、固定 Top-K 多 Agent、无证据去重、无风险审查、无拒答机制，以及组合层消融（统一约束优化、逆波动率、风险平价与 PPO）。

除累计收益、Sharpe、最大回撤和换手外，还应报告：

- 证据引用覆盖率、过期/不可得证据拦截率和回放完整率；
- Agent 分歧率、拒答率、拒答后的风险结果与人工复核案例；
- 成本前后表现差、交易被成本门控拦截的比例；
- 结论稳定性：同一证据在重复运行或轻微扰动下的行动一致性。

## 8. 范围与阶段性交付

首阶段完成可回放的 PIT 证据账本、单资产 ResearchPacket、基础委员会、Signal Compiler、成本感知约束优化、模拟执行和完整审计轨迹。第二阶段接入财务披露和记忆校准，第三阶段在统一接口、成本和风险条件下进行 PPO、逆波动率与风险平价的公平比较。

项目不以真实资金自动交易、收益承诺或替代投资建议为目标；所有执行首先限定为模拟环境，并保留人工审批边界。

## 9. 参考方向

- FinRL：金融强化学习框架与可复现实验环境。
- TradingAgents：角色化多 Agent 金融交易框架。
- FinMem、FinAgent：金融 Agent 的记忆与反思机制。
- ReAct、Reflexion：工具调用、轨迹与反思式 Agent 的通用方法。
- SEC EDGAR API：公开公司申报文件及其可得时间的权威数据来源。
- Markowitz（1952）：均值—协方差组合选择。
- Black–Litterman（1992）：中性先验与带置信度观点融合。
- Jagannathan 与 Ma（2002）：权重约束与估计风险。
- Lobo、Fazel 与 Boyd（2007）：交易成本和约束下的组合优化。
